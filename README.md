# 实验室设备预约管理系统

C++17 + Qt6 (Widgets/Charts) + CMake 构建的实验室设备预约管理系统。

## 架构

- `include/` + `src/`：核心业务逻辑静态库 `labres_core`（设备/预约/保养/用户/时间管理）
- `ui/`：Qt Widgets 图形界面 `labres_ui`（登录、主窗口、设备管理、预约、保养、统计、审批、仪表盘）

## 功能

- 用户登录（学生/教师/管理员三种角色）
- 设备台账管理（增删改查、CSV 导出）
- 预约管理（时段冲突检测、可用时段查询、取消预约、状态筛选）
- 保养任务管理（周期扫描、执行保养）
- 审批流（待审批→已通过→已归还）
- 统计分析（预约次数柱状图、设备状态饼图、使用率图）
- 首页仪表盘（KPI 卡片、最近预约、设备状态分布）
- 磨砂玻璃风格 UI（渐变背景、半透明侧栏、圆角卡片）

## 构建

```bash
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH=<Qt6路径> -DBUILD_UI=ON
cmake --build build
```
